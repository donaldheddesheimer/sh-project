# Signal controllers

Reserved for signal-control assets that sit on top of a network's base timing:

- alternative timing plans (SUMO `tlLogic` additional files) that can be loaded
  per scenario;
- per-step control strategies such as emergency-vehicle preemption for the
  "green corridor" candidate (milestone 2).

The base fixed-time plans (90 s cycle, eastbound green wave) currently live in
`../networks/grid3x3/grid3x3.net.xml`, generated by `build_network.py`. Runtime
timing changes go through `SignalPolicy` → `SafetyValidator` →
`TrafficSimulation.apply_signal_policy()` in the backend.
